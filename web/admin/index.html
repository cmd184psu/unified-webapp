Module Access

A module is either open or protected. Protected modules always accept an LDAP (or passkey) sign-in; giving a module a pin file also lets it accept a standalone door-code PIN. Admin's PIN source is shown read-only below (see Operator PIN).

      Operator PIN (admin door-code)

      Changing the file or PIN takes effect immediately -- make sure you know the new PIN before signing out.
